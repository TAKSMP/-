# ゆうゆうの丘公園 — 歩行フィールド v1

## すぐに確認
`preview.html` をブラウザで開くと、通信やインストールなしで歩行サンプルが動きます。
スマートフォンでは左下のパッドをドラッグ、PCではフィールドをクリックして矢印キー／WASDで移動します。
「通行範囲」で水色の許可範囲と赤い障害物を確認できます。水色以外も通行禁止です。

## 内容
- `assets/background.png`：1213 × 1296 px、不透明PNG。文字・モンスターボールなし。
- `map.json`：開始位置、通行可能な多角形／園路、障害物、イベント領域、カメラ設定。
- `field.js`：依存ライブラリ不要のCanvas 2D描画・連続移動・追従カメラ・衝突判定。
- `field.css`：スマホ用操作パッドとHUD。
- `YuyuuField.jsx`：React組み込み例。
- `index.html`：分離ファイルを使う動作サンプル（HTTPサーバーが必要）。
- `preview.html`：同じデータを内包した単一HTML版。
- `tests.mjs`：通行判定と園路の連続性の検証。`node tests.mjs`。

## 現在のアプリとの関係
2026-09-21取得の https://taksmp.github.io/-/ の配信HTMLでは、Reactと、セルをタップして進むストーリーマップを確認しました。自由歩行エンジンへの接続済みデータではありません。本パッケージは独立したフィールド部品です。公開サイト・既存の図鑑・セーブデータには変更を加えていません。

## Reactに組み込む
1. `map.json` と `assets/` を `public/fields/yuyuu/` にコピー。
2. `field.js`、`field.css`、`YuyuuField.jsx` を `src/fields/` にコピー。
3. フィールドを表示したい画面でコンポーネントを使います。

```jsx
import YuyuuField from './fields/YuyuuField.jsx';

<YuyuuField
  assetBase="./fields/yuyuu/"
  paused={battleOpen}
  onZoneEnter={(zone, position) => {
    // zone.id: north-grass / rest-area / south-grass
    // 既存の虫データや戦闘画面にここから接続。
    // 同じ領域にいる間は再発火せず、入り直したときに発火。
  }}
  onError={console.error}
/>
```

GitHub Pagesの `/-/` 配下に対応する相対URLです。別の階層で呼び出す場合は `assetBase` を調整してください。保存・戦闘・虫出現の抽選はホストアプリ側の責務です。既存のストーリー進行ロジックをそのまま置き換える処理は含みません。

## データの約束
原点は画像左上、右が+x、下が+y。すべて背景画像のピクセル座標です。キャラクター座標は足元です。
`walkable.polygons` と `walkable.corridors` の和集合から `obstacles` を除き、外側は通行禁止。
半径6pxの足元判定を中心と外周8点でサンプリングし、最大2pxの小刻みな移動で障害物のすり抜けを抑えます。斜め移動の速度補正・壁沿いの移動・非表示時の入力リセットを実装しています。
カメラはキャラクターに追従し、マップ端で止まります。端付近のみキャラクターが画面中央からずれます。常時中央が必要なら `camera.clampToMap=false` にできますが、画像外の余白が見えます。

独自キャラクターは `createField` の `drawPlayer(ctx, state)` で描画できます。ctxはワールド座標、state.x/yは足元。サンプルの探検家は仮の図形キャラクターです。

## 制作上の範囲と制約
これは一枚背景方式の、組み込み前の実動プロトタイプです。ゲーム向けの地形を写真と生成画像から手作業で概略設定しています。測量データや現地施設の正確な案内には使わないでください。
背景はタイルセットではなく、木・建物・地面が一枚に描かれています。木の樹冠全体を通行禁止にする設計のため、木の裏を歩く・建物へ入る・前景にキャラクターが隠れる表現はありません。南側の遊具・砂場の一部も通行禁止です。これらが必要な場合は地面と前景を別の素材として制作してください。
当たり判定は見た目に合わせた概略の範囲です。本番投入前には利用端末で狭い園路の操作感を確認し、map.jsonを調整してください。PNGの拡大はドット調を維持しますが、元画像は均一なピクセルグリッドのタイル素材ではありません。
虫の領域は接続例であり、生息情報や出現確率は含みません。サンプルは外部通信・分析送信・localStorageへの書き込みを行いません。
背景は組み込みの画像生成機能で制作。最終編集指示は「看板だけを除去し、園路・遊具・樹木・建物の位置と画像寸法を維持。文字・UI・キャラクター・アイコンなし」。
