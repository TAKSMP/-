# 鶴瀬・道路マスク固定マップ v4

## 2つのZIPを展開

1. `tsuruse-mask-v4-main.zip` を展開します。
2. `tsuruse-mask-v4-south-tiles.zip` を展開し、`south-tiles` 内の112個のWebPを、メインの `tsuruse-mask-v4/tiles/` に追加します。フォルダ全体を置き換えないでください。
3. `tiles` が240ファイルになれば完了です。

`mask-check.html` は直接開ける道路照合ビューです。中央・北部・南部で背景と50%マスク重ねを切り替え、原寸表示できます。

## 歩行デモ

このフォルダで `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、`http://localhost:8000/` を開きます。Macは `start-preview.command` でも起動できます。
「歩き始める」でカメラがプレイヤーを追従します。矢印／WASD、画面左下のパッド、道路タップに対応。判定はプレイヤーの足元1点です。

## 既存アプリへの組み込み

`map.json`、`tiles.json`、`overview.png`、`roads-mask.png`、`tiles/` をアプリの公開フォルダ `fields/tsuruse-mask/` にコピーします。
Reactの場合は `TsuruseWorld.jsx`、`viewer.js`、`viewer.css`、`navigation.js`、`tile-store.js` をソースに追加し、`<TsuruseWorld assetBase="./fields/tsuruse-mask/" />` を表示します。サブパス配信ではアプリのBASE_URLに合わせたassetBaseを指定してください。
既存アプリへのデプロイは行っていません。

## 解像度と描画

- 元座標2048×1885。1座標を16×16画素に固定した32768×30160画素相当。
- 240枚の可逆WebP。通常2048×2048、最下段の高さ1488。
- 道路は元マスクを最近傍で16倍に配置。平滑化・膨張・収縮・途切れの補完なし。
- 道路色RGB(133,155,169)を予約し、道路外にはこの色を使いません。
- 手描き素材は8種の家、4種の木、4種の庭を反復配置。各素材は縮小のみで、拡大して精細さを装っていません。全域を一枚ずつ描き分けた絵ではありません。
- 家8529、木6126、庭2639。建物位置・植生は装飾としての創作で、現実の建物配置ではありません。
- グローバル座標で配置・地面テクスチャを共有するため、タイルごとに模様が再開しません。
- マスク由来の階段状の道路端は意図的に保持。芝生や公園らしい装飾でも、元マスクが黒なら歩けません。
- 全体図は読込待ち・遠景用です。歩行時は原寸タイルを読み込み、最大8倍表示×端末画素比2で16画素密度に対応します。
- キャッシュ12枚、並列読込3。画像の展開だけで最大約192MiBを使います。スマホ実機での性能は未確認です。

## 検証と再生成

`verification.json` に、保存後の全240画像を再読込した道路ピクセル比較、装飾の道路侵入、素材の拡大、代表5区画の独立拡張レンダリングとの比較を記録しています。元の白い画素227599、出力の道路画素58265344です。
`qa/` に原寸3区画と50%マスク重ね画像があります。
`test-navigation.mjs` はマスクRLE・タイル数・歩行経路を検証します。`node test-navigation.mjs` で実行できます。ブラウザーおよびスマホ実機での操作試験は未実施です。
`assets/` に生成済み素材、`placements.json` に全配置、`build.py` に固定シード20260922の再生成コードを収録。PythonのPillow、NumPy、SciPyが必要です。`finish.py` は隣接する旧v2コードを取り込む初期組立用で、通常のアプリ実行には不要です。
