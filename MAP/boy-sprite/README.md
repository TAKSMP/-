# あるく 男の子の ドット絵

`source.webp` が もとの 絵（1086×1448、はいけいは とうめい）。
よこ3コマ × たて4れつ で ならんでいる。

ゲームで つかうのは `public/fields/boy.png`。
つくりかた：

1. コマごとの きっちりした はんいを アルファで さがす
2. したから 22% の よこの まんなか ＝ あしもと として そろえる
3. 1ます 132×128 に そろえて ならべ、128しょくに おとす（245KB → 47KB）

れつの いみ：0=まえ、1=よこ（つかわない）、2=みぎ、3=うしろ。
もとの 絵は 1れつめも かおが みぎを むいているので、
ひだりむきは 2れつめ（みぎ）を さゆう はんてん して つかっている。
（`src/components/FieldMap.tsx` の drawSprite）
