# 鶴瀬駅周辺 イラスト背景 v3 — 接続調整前

13区画すべての背景画像を作成しました。前版のベクター背景を置き換えるためのイラスト素材です。屋根、庭、樹木、植え込みを画像生成で描き込んでいます。

**背景の制作・読み込み用パッケージです。道路接続・当たり判定を完成させた歩行ゲームではありません。**

## 確認方法

`preview.html` をブラウザーで開いてください。素材を内包した単体HTMLです。区画を選択し、「元画像と比較」で同じ範囲を切り替えられます。ドラッグで移動、＋／−またはホイールでズームできます。

`index.html` はHTTPで画像を個別に読む版です。このフォルダーで `python3 -m http.server 8000` を実行し `http://localhost:8000` を開いてください。

## 納品内容

- `assets/0_1.png` など：13区画の生成原寸PNG。隣接確認用の重なりを含みます。
- `assets/original.png`：元の全体イラスト、1307×1203。
- `map-art-review.png`：4575×4211の全体合成。**継ぎ目修正前**。13区画を所定位置に並べた確認用です。
- `overview-review.png`：軽量な全体確認図。
- `manifest.json`：区画の配置座標、画像の実寸、描画時に使用する範囲。
- `background.js`：Canvas用の背景読込・描画処理。同時読込2枚、保持最大16枚。
- `preview.html`：全素材を含む単体比較画面。初回読込が大きいためアプリ本番には使わないでください。
- `index.html`、`preview.js`：HTTPで個別画像を読む比較画面。
- `references/`：詳細画像の生成に使用した参照区画。
- `generation-prompts.txt`：生成方式・指示。

## 解像度とズーム

区画画像は、おおむね幅1267〜1341pxです。同じ範囲の元画像に対して最低約3.54画素／元画像1画素の密度で描き直しました。全体合成は倍率3.5で配置した4575×4211pxです。単純な拡大処理だけで細部を増やしたものではありません。

Canvasで `zoom` を「CSS画素／元画像座標1単位」とした場合、画像の画素数を超えずに表示できる目安は `zoom * devicePixelRatio <= 3.54` です。DPR2なら約1.77倍、DPR1なら約3.54倍まで。比較画面はDPR上限2、初期倍率1.7です。それ以上も拡大できますが、画素の補間が入り、無制限に鮮明にはなりません。

以前の2048×1885の地図座標を8倍表示する設定と同等の拡大に耐える解像度ではありません。さらに大きな歩行倍率にする場合、区画をもっと細分化した描き直しが必要です。

## アプリへの取り込み例

`assets/` と `manifest.json` を `public/fields/tsuruse-art/` に、`background.js` をソース側に置きます。

```js
import {loadIllustratedMap} from './background.js';
const background = await loadIllustratedMap({
  baseUrl: new URL('./fields/tsuruse-art/', document.baseURI).href
});

// ゲームの描画ループで、キャラクターより前に呼び出す。
const dpr = Math.min(window.devicePixelRatio || 1, 2);
canvas.width = Math.round(cssWidth * dpr);
canvas.height = Math.round(cssHeight * dpr);
background.draw(ctx, {
  cx: cameraX, cy: cameraY,
  zoom: 1.7, width: cssWidth, height: cssHeight, dpr
});
// 画面を閉じるとき
background.destroy();
```

座標は **今回の全体イラストの1307×1203** が基準です。元の地図データ2048×1885とは異なります。`sourceRect` は区画PNG内の切り出し範囲 `[sx,sy,sw,sh]`、`x,y,width,height` は全体イラスト座標での配置範囲です。

読み込み中は元画像を背景に表示します。画像の失敗は5秒後から再試行します。全13枚を読み込んだときの画像本体のRGBA換算は約80MiBで、実際にはブラウザーやCanvas等の追加メモリーが必要です。

## 道路・区画接続の状態

- 全区画とも元の配置を参照していますが、生成で道路の曲がり方・幅・家の配置が変わっています。
- 元画像はイラストであり、実際の街路を測量したデータではありません。
- 重なりを付けて生成しましたが、境界の道路が完全には一致しません。色味や描画密度にも区画差があります。
- 合成画像・表示用配置情報は確認用で、無修正で通り抜けられるシームレス背景の保証ではありません。
- 前版の当たり判定をそのまま重ねると道路外を歩く可能性があります。新しい絵に対して道路と公園入口を確認し直す必要があります。
- 公開アプリのコード・データは変更していません。

## 検証
