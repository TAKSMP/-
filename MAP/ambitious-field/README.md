# アンビシャス — アプリ組み込み用フィールド

## 試す
ZIPを解凍して `preview.html` をChrome等のブラウザで開いてください。画像も内包した単一HTMLで、通信不要です。左下のパッド、または画面をクリック後に矢印キー／WASDで移動します。「上の入口」「右の入口」「下の入口」で開始位置を切り替え、「通行範囲」で判定を表示できます。

## 内容
- `assets/background.png`：1437×1095 px。最新の修正マップに公園南入口の歩道を追加。
- `map.json`：ステージID `ambitious`、名前「アンビシャス」、公園・道路の通行範囲、3つの入口、開始位置、イベント領域。
- `field.js` / `field.css`：Canvas描画、キャラクター追従、衝突判定、スマホ操作。
- `AmbitiousField.jsx`：React組み込み用部品。
- `preview.html`：単一ファイルの歩行サンプル。
- `index.html`：HTTPサーバー上で使う分離ファイル版サンプル。
- `walkable-overlay.svg`：背景に判定を重ねた確認図。水色＝公園、紫＝道路・通路、赤＝障害物。表示色は背景PNGには含みません。
- `tests.mjs` / `validation.json`：検証コード／結果。

## Reactへ取り込む
1. `map.json` と `assets/` をアプリの `public/fields/ambitious/` にコピー。
2. `field.js`、`field.css`、`AmbitiousField.jsx` を `src/fields/` にコピー。
3. 表示する画面に次のように配置します。

```jsx
import AmbitiousField from './fields/AmbitiousField.jsx';

<AmbitiousField
  assetBase="./fields/ambitious/"
  entry="north"
  paused={false}
  onZoneEnter={(zone, position) => {
    // park-upper / park-lower。既存の虫出現・戦闘処理に接続。
  }}
  onError={console.error}
/>
```

`entry` は `north`（上）、`east`（右）、`south`（下）から選択できます。戦闘中は `paused=true` にします。GitHub Pagesの `/-/` 配下を考慮した相対URLです。ルーティングによって階層が変わる場合はassetBaseを調整してください。
既存のゆうゆうの丘公園パッケージと同じ `schemaVersion: 1` 形式です。既存エンジンに新しい `map.json` と画像を読み込ませる方法でも利用できます。入口切替APIは今回の `field.js` に追加されています。

## 通行仕様
原点は背景画像の左上、xは右、yは下、単位は画像ピクセル。位置はキャラクターの足元です。背景画像を単独で拡縮・トリミングすると判定がずれるので、描画変換で拡縮してください。
`walkable.polygons` と `walkable.corridors` の和集合から `obstacles` を除いた部分が通行可能。それ以外は通行禁止です。
公園は上下の広場と間の通路を歩けます。北・東・南の入口が接続しています。南入口は住宅と駐車場を避ける歩道を背景に追加しました。
足元半径5px、外周8点サンプル、最大2px単位の移動判定。カメラはキャラクターに追従し、マップ端で止まります。端付近のみキャラクターが中央からずれます。
灰色道路の主要経路、マンションへのアクセス路を収録。建物内、駐車場内、線路、テニスコート、住宅の庭には入れない設計です。描かれた細い私道や門内の舗装面は必ずしも通行許可していません。

## 検証
`node tests.mjs` で、3入口から2つの公園広場への接続、各入口の通路自体の連続性、マンション・駐車場・コート・線路の禁止位置、大きな移動量での判定を確認できます。
背景と判定を重ねて位置を目視確認し、公園内の木や南入口を調整済みです。ブラウザ実行環境を利用できなかったため、実画面の動作・スマホ実機・Reactアプリとの結合は未検証です。公開前に操作感を確認してください。

## 範囲
これは追加ステージ用の独立部品です。公開中のアプリへのコード反映・デプロイ・既存のセーブデータ変更は行っていません。現在のマスターデータ形式に合わせたステージ登録、虫の出現、戦闘接続はアプリ側で行ってください。
一枚背景方式で、木の背後にキャラクターが隠れる前景レイヤーはありません。試歩行のキャラクターは仮の図形です。生成済みの虫取り少年は今回のパッケージに組み込んでいません。`createField` の `drawPlayer(ctx,state)` で独自スプライトに差し替えられます。
画像を基にしたゲーム用概略地形で、現実の測量・通行案内用ではありません。画像生成は組み込み機能を使用し、最後の編集は「中央下の道路から公園南東端へ、住宅間の隙間を通る細い歩道を追加。それ以外の構成を維持」です。
